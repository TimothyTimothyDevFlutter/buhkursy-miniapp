# Как обновить сайт

Памятка на один экран. Держите её под рукой — этим вы будете пользоваться регулярно.

**Адрес приложения:** https://timothytimothydevflutter.github.io/buhkursy-miniapp/

**Папка на компьютере:** `c:\projects\courses_web_view`

**Файл, который вы правите:** `docs\data.js` — цены, расписание, телефоны, тексты.
Остальные файлы трогать не нужно.

---

## Способ 1. Попросить меня

Откройте проект и напишите обычными словами:

> Поменяй цену группового занятия на 120 000 и выложи

Я поправлю файл, проверю, что страница не сломалась, и загружу изменения.

---

## Способ 2. Сделать самому

**Шаг 1. Поправить файл.**
Откройте `docs\data.js` в редакторе, поменяйте что нужно, нажмите `Ctrl+S`.

**Шаг 2. Посмотреть, что получилось.**
Откройте `docs\index.html` двойным щелчком и нажмите `F5`. Изменение должно быть видно.
Если страница стала пустой — вы потеряли запятую или кавычку. Нажмите `Ctrl+Z`
столько раз, сколько нужно, чтобы вернуть как было.

**Шаг 3. Отправить в интернет.**
В редакторе нажмите `` Ctrl+` `` — внизу откроется чёрное окно. Вставьте туда
три строки, по одной, каждый раз нажимая Enter:

```
git add -A
git commit -m "Поменял цену"
git push
```

Текст в кавычках во второй строке — ваше короткое описание, пишите что угодно.

**Шаг 4. Подождать минуту.**
Обновление появляется на сайте примерно через 30–60 секунд.
Откройте адрес и нажмите `Ctrl+F5` — это обновление с принудительной
перезагрузкой, без него браузер покажет старую сохранённую копию.

---

## Если на сайте всё ещё старая версия

По порядку, сверху вниз:

1. Нажали `Ctrl+F5`, а не просто `F5`? Браузер хранит копию страницы и по обычному
   обновлению показывает именно её.
2. Прошла ли минута? GitHub пересобирает сайт не мгновенно.
3. Файл сохранён? В редакторе на вкладке не должно быть белого кружка вместо крестика.
4. Команда `git push` отработала без красного текста?

Проверить, что именно лежит в интернете прямо сейчас, можно здесь:
https://github.com/TimothyTimothyDevFlutter/buhkursy-miniapp/blob/main/docs/data.js

Это тот же `data.js`, но уже на стороне GitHub. Если там старая цена — изменения
не доехали, дело в шаге 3. Если новая, а на сайте старая — дело в браузере, шаг 1.

---

## Если сломали и хотите вернуть как было

Ничего не потеряно: GitHub хранит все прошлые версии. Напишите мне
«верни прошлую версию сайта» — или сами в чёрном окне:

```
git checkout -- docs/data.js
```

Эта команда возвращает `data.js` к последнему сохранённому состоянию.
