# Настройка заявок

Один раз на 15 минут. После этого форма заработает и заявки будут приходить
вам в Telegram.

**Важно про токен.** Вы вставите его в личный кабинет Cloudflare. Ни в один
файл проекта он не попадёт — репозиторий публичный, там его увидели бы все.
Мне присылать токен тоже не нужно.

---

## Шаг 0. Разрешите боту вам писать

Откройте в Telegram своего бота **@buhkursy_uz_bot** и нажмите «Запустить»
(или отправьте `/start`).

Это обязательно. Telegram запрещает боту писать первым — без этого шага
заявки будут уходить в никуда, и вы об этом не узнаете.

---

## Шаг 1. Заведите аккаунт Cloudflare

Откройте https://dash.cloudflare.com/sign-up

Почта и пароль. Карта не нужна, платить ни за что не придётся: бесплатного
тарифа хватает на 100 000 заявок в день.

Подтвердите почту по письму, которое придёт.

---

## Шаг 2. Создайте Worker

Worker — это и есть тот маленький скрипт-посредник.

1. В левом меню найдите **Workers & Pages** (или Compute).
2. Нажмите синюю кнопку **Create** → вкладка **Workers** → **Create Worker**.
3. В поле имени впишите:

```
zayavki
```

4. Нажмите **Deploy**. Cloudflare создаст пустой скрипт-заглушку.

---

## Шаг 3. Вставьте код

1. На странице созданного Worker нажмите **Edit code** (или «</> Edit code»).
2. Откроется редактор с чужим кодом внутри. Выделите там **всё** (`Ctrl+A`)
   и удалите.
3. Откройте файл `worker/zayavki.js` из папки проекта, скопируйте **весь** текст
   и вставьте в редактор Cloudflare.
4. Нажмите **Deploy** справа сверху.

---

## Шаг 4. Положите токен и ваш номер в хранилище

Возвращайтесь на страницу Worker → вкладка **Settings** → раздел
**Variables and Secrets**.

Добавьте **две** переменные кнопкой **Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret (секрет) | токен от BotFather, длинная строка с двоеточием |
| `CHAT_ID` | Text (обычная) | `6029626760` |

Для `BOT_TOKEN` обязательно выберите тип **Secret** — тогда значение
спрячется даже от вас самих, его нельзя будет подсмотреть в панели.

Нажмите **Deploy**, чтобы изменения вступили в силу.

---

## Шаг 5. Скопируйте адрес приёмника

На главной странице Worker есть адрес вида:

```
https://zayavki.ваше-имя.workers.dev
```

Скопируйте его целиком.

---

## Шаг 6. Впишите адрес в проект

Откройте `docs/data.js`, найдите раздел `form` (примерно строка 180) и вставьте
адрес в пустые кавычки:

```js
form: {
  url: 'https://zayavki.ваше-имя.workers.dev',
```

Сохраните (`Ctrl+S`) и отправьте на сайт тремя командами:

```
git add -A
git commit -m "Включил заявки"
git push
```

Через минуту форма появится на странице.

**Пока это поле пустое, формы на странице нет.** Так задумано: лучше не показывать
форму вовсе, чем показывать ту, которая молча теряет заявки.

Можно просто попросить меня: «вставь адрес приёмника» и прислать адрес —
сделаю сам.

---

## Как проверить, не дожидаясь настоящих заявок

**Проверка 1. Работает ли приёмник.**
Откройте адрес Worker в браузере. Должна появиться строка:

```
{"ok":false,"error":"Сюда нужно отправлять заявку, а не открывать в браузере"}
```

Это правильный ответ. Значит, скрипт жив и отвечает.

**Проверка 2. Доходит ли до Telegram.**
Откройте приложение, заполните форму своим именем и телефоном, отправьте.
Сообщение должно прийти вам в чат с ботом за пару секунд.

**Проверка 3. Что видит человек при обрыве связи.**
Включите на телефоне авиарежим, откройте приложение (оно уже загружено),
заполните форму и нажмите отправку. Вместо пустого экрана должна появиться
розовая карточка «Не получилось отправить» с кнопкой телефона.

**Проверка 4. Пустая заявка.**
Нажмите «Отправить» с пустыми полями. Под полями появятся подсказки,
отправки не произойдёт.

---

## Если заявки не приходят

Проверяйте по очереди, это разделяет проблему надвое:

1. **Открывается ли адрес Worker в браузере** и выдаёт ли строку из проверки 1.
   Нет — дело в шагах 2–3, код не вставился или не задеплоился.
2. **Нажимали ли вы «Запустить» у своего бота** (шаг 0). Это самая частая причина:
   всё работает, но Telegram не даёт боту написать вам первым.
3. **Правильно ли записан `CHAT_ID`** — должно быть `6029626760`, без пробелов.
4. **Тип `BOT_TOKEN`** — должен быть Secret, а сам токен вставлен целиком,
   вместе с цифрами до двоеточия.

Логи Worker: страница Worker → вкладка **Logs** → **Begin log stream**.
Там видно каждую заявку и причину отказа.

---

## Если токен всё-таки утёк

Не паникуйте, но сделайте сразу: откройте @BotFather → `/revoke` → выберите бота.
Он выдаст новый токен, старый мгновенно перестанет работать. После этого
замените значение `BOT_TOKEN` в Cloudflare на новое.
